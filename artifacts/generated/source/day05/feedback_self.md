# Глоссарий

- Linear independence (линейная независимость) - уравнение \(Ax=0\) имеет только решение \(x=0\).
- Linear dependence (линейная зависимость) - существует ненулевой \(x\), для которого \(Ax=0\).
- Span (линейная оболочка) - множество всех линейных комбинаций заданных векторов.
- Basis (базис) - independent set, который порождает нужное пространство.
- Row space (пространство строк) - пространство \(C(A^T)\).
- Column space (пространство столбцов) - пространство \(C(A)\).

# Что поправить

1. Если в \(\mathbb{R}^m\) векторов больше, чем \(m\), они обязательно dependent. Но такой набор может породить всё \(\mathbb{R}^m\). Пример: стандартный basis пространства \(\mathbb{R}^3\) вместе с четвёртым лишним вектором.

2. Если в \(\mathbb{R}^m\) векторов меньше, чем \(m\), они не могут породить всё \(\mathbb{R}^m\). Но они могут быть independent. Пример: два первых стандартных вектора в \(\mathbb{R}^3\).

3. В классификациях полезно явно закрывать все пункты. Для \(S_1\) надо дописать: набор не является basis для \(\mathbb{R}^3\). Для \(S_3\): набор не порождает \(\mathbb{R}^2\).

4. Row operations не отправляют столбцы в другое пространство. До и после elimination столбцы имеют \(m\) компонент и лежат в \(\mathbb{R}^m\). Точное различие такое:

\[
C(R)\ne C(A)\quad\text{в общем случае},
\qquad
C(R^T)=C(A^T).
\]

Поэтому basis для \(C(A)\) берём из pivot columns исходной \(A\), а basis для row space удобно брать из ненулевых строк \(R\).
